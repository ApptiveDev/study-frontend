# 과제 1: 채팅 입력 임시 저장 기능 만들기

![채팅 화면 예시](./.docs/example.gif)

APPTIVE는 프론트엔드 스터디 참여자들의 원활한 소통을 위하여 채팅 기능을 제공하고 있습니다.

카카오톡 등의 어플리케이션에서는 채팅 입력창에 글을 작성하다가 실수로 다른 화면으로 이동했을 때, 작성하던 글이 사라지지 않도록 임시 저장 기능을 제공합니다. 이와 같은 기능을 구현하여, 사용자가 채팅 입력창에 작성하던 글이 사라지지 않도록 해 주세요.

## 요구사항 1

[`useDebounce`](./src/lib/hooks/debounce.js) 훅을 만들어 보세요. 이 훅은 입력값이 변경된 후 일정 시간(delay)이 지난 뒤에 콜백 함수를 실행하도록 합니다. 이를 통해 사용자가 입력을 멈춘 후에만 상태가 업데이트되도록 할 수 있습니다.

```js
useDebounce(() => {
  // 입력값이 변경된 후 delay 시간이 지난 뒤에 실행할 코드
}, 500); // 500ms, 0.5초
```

## 요구사항 2

[`useStorageState`](./src/lib/hooks/storage.js) 훅을 만들어 보세요. 이 훅은 상태를 `localStorage` 또는 `sessionStorage`에 저장하고, 컴포넌트가 마운트될 때 저장된 값을 불러오는 기능을 제공합니다. 이를 통해 사용자가 입력한 글이 브라우저 세션 동안 유지되도록 할 수 있습니다.

`useStorageState` 훅은 `useDebounce`에 의존하도록 구현해 보세요. 사용자가 입력을 멈춘 후에만 상태가 저장되도록 구현해 보세요.

```js
const [text, setText] = useStorageState('chat-input', '');
```
